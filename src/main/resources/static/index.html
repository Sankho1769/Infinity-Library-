📤 Issue Physical Book Copy

Protected by SELECT ... FOR UPDATE Row-Level Write Lock
* System will acquire an exclusive pessimistic row lock on the physical copy, check borrowing quota (≤ 5), verify member status (ACTIVE), and snapshot the loan policy (14 days default).

📥 Return Physical Book Copy

Deterministic fine calculation & FIFO hold reallocation
* Overdue duration is computed using the library's official Clock. If overdue, a fine record is accrued ($0.50/day). If pending reservations exist, the copy is automatically allocated to the next member in line.

🛡️ Broken Object-Level Authorization (BOLA/IDOR) Defense

In unhardened systems, a member can manipulate URL query parameters (e.g. /api/v1/members/2/loans) to peek into another patron's private loans and fines. In Infinity Library, Spring Security method-level authorization inspects authentication.principal.memberId.
